# Harmony Notch

Harmony Notch is a Huawei-inspired notch and status-bar experience for supported Android devices.

## Contributing

Harmony Notch is open for community contributions.

You can inspect the source code, create a fork, make changes and submit a Pull Request.

Pull Requests are reviewed manually and are not guaranteed to be accepted.

Please read `LICENSE` before using any part of this project's source code.

## Reporting bugs

Found a bug? Open an Issue and describe:

* What happened
* What you expected to happen
* Your device
* Your Android/HarmonyOS version
* Steps to reproduce the problem

## Feature requests

Have an idea for Harmony Notch? Open an Issue and explain what you'd like to see and why.

Thanks for helping improve Harmony Notch!
