# Contributing to Harmony Notch

Thanks for wanting to help improve Harmony Notch!

## How to contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make and test your changes.
4. Push your branch to your fork.
5. Open a Pull Request to the `main` branch of this repository.
6. Explain what you changed and why.

All Pull Requests will be reviewed by the project owner.

A Pull Request may be accepted, rejected, or requested to be changed before it is merged.

## Important

Submitting a Pull Request does not guarantee that your changes will be accepted.

Please do not submit code that you do not have permission to use.

Please read the project's LICENSE file before contributing.
